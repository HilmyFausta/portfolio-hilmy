SIGBOT — Notifikasi Tiket ManageEngine

Notifikasi WhatsApp otomatis setiap ada tiket baru, mendekati deadline, atau macet — lengkap dengan saran dari AI lokal.

n8nWAHAOllamaPython

Masalah yang diselesaikan

Tim helpdesk perlu tahu status tiket ManageEngine ServiceDesk Plus secara real-time tanpa harus terus-menerus membuka dashboard. API ManageEngine sendiri punya keterbatasan — hanya bisa menarik 10 tiket terbaru sekali panggil — sehingga dibutuhkan pendekatan lain untuk data yang lebih lengkap.

Cara kerja

  • Script Python terpisah berjalan lewat cronjob, mengunduh tiket ke database JSON lokal (bootstrap 1000 tiket saat database masih kosong, lalu mode normal menarik 50 tiket terbaru)
  • Workflow n8n bernama SIGBOT berjalan tiap 3 menit: membaca JSON hasil cronjob, memfilter tiket berdasarkan grup "Site Support Helpdesk Tuban", lalu mengkategorikannya menjadi tiket baru, mendekati deadline, overdue, macet, atau selesai
  • Untuk tiap kategori, AI lokal (Ollama) membantu menyusun saran singkat sebelum pesan diformat dan dikirim ke grup WhatsApp lewat WAHA

Detail teknis

Pelacakan notifikasi yang sudah terkirim (supaya tidak dobel) disimpan di static data workflow n8n, bukan di database tiket itu sendiri — menjaga logika dedup tetap terpisah dari data mentah tiket.
