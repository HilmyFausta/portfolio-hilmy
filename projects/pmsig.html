Web PM SIG — Preventive Maintenance Checklist

Web checklist untuk preventive maintenance aset kantor: PC, laptop, printer, dan switch.

Web AppPM2

Tentang proyek

Dikerjakan berdua dengan rekan magang, web ini menggantikan pencatatan manual preventive maintenance aset kantor menjadi checklist digital yang lebih mudah dipantau statusnya.

Deployment

Frontend di-build dengan pnpm run build dan backend dijalankan lewat PM2, keduanya berjalan di PC kantor dan diakses lewat HTTPS dalam jaringan LAN internal — bukan hosting publik.

Rencana lanjutan

Integrasi notifikasi WhatsApp untuk checklist yang selesai/menunggu approval, pengingat mendekati deadline periode PM, serta rekap harian per kategori aset — mengikuti pola yang sudah terbukti di proyek SIGBOT, lewat API khusus di backend PMSIG yang dijaga service key.
